1. 프로젝트 제안

주제

이번 프로젝트의 주제는 손글씨 숫자 이미지 분류이다.

주제 선택 이유

처음에는 인공지능이나 딥러닝이라는 말이 조금 어렵게 느껴졌다. 그래서 너무 복잡한 주제보다는 결과를 눈으로 바로 확인할 수 있는 주제가 좋겠다고 생각했다. 손글씨 숫자는 0부터 9까지 정답이 분명하고, 이미지도 비교적 단순해서 처음 프로젝트로 다루기 괜찮아 보였다.

사람이 손으로 숫자를 쓰면 같은 숫자라도 모양이 조금씩 다르다. 예를 들어 숫자 2도 어떤 사람은 둥글게 쓰고, 어떤 사람은 각지게 쓴다. 이런 차이가 있는데도 컴퓨터가 숫자를 구분할 수 있는지 확인해보고 싶었다.

아직 프로그래밍과 머신러닝을 많이 배운 상태는 아니기 때문에, 처음부터 어려운 딥러닝 모델을 직접 만들기보다는 scikit-learn에서 제공하는 예제 데이터셋을 이용해서 기본적인 이미지 분류 과정을 따라가보는 것을 목표로 정했다.

최종적으로 확인하고 싶은 내용

  • 손글씨 숫자 이미지가 컴퓨터 안에서는 어떤 데이터로 표현되는지 확인한다.
  • 컴퓨터가 이미지의 어떤 정보를 이용해서 숫자를 구분하는지 이해해본다.
  • 데이터를 학습용과 테스트용으로 나누는 과정을 해본다.
  • 간단한 분류 모델을 사용해서 숫자를 예측해본다.
  • 모델이 맞힌 숫자와 틀린 숫자를 확인해본다.
이 페이지는 최종 결과물이 아니라 현재까지의 진행 과정을 정리한 중간 블로그이다. 현재는 주제 선정, GitHub 블로그 생성, 데이터셋 조사, 기본 코드 이해 단계까지 진행하였다.

3. 데이터셋 조사

사용할 데이터셋

이번 프로젝트에서는 scikit-learn에서 제공하는 digits 데이터셋을 사용하려고 한다. 이 데이터셋은 손으로 쓴 숫자 이미지들로 이루어져 있고, 각 이미지는 0부터 9까지의 숫자 중 하나이다.

이 데이터셋을 선택한 이유는 따로 이미지를 직접 모으지 않아도 되고, 파이썬에서 바로 불러올 수 있기 때문이다. 또한 이미지 크기가 8×8로 작아서 처음 실습하기에 부담이 적다고 생각했다.

항목 내용
데이터셋 이름 scikit-learn digits dataset
데이터 종류 손글씨 숫자 이미지
분류 대상 0부터 9까지의 숫자
이미지 크기 8 × 8 픽셀
입력 데이터 이미지를 이루는 픽셀 값
예측해야 하는 값 실제 숫자 라벨

데이터를 이해한 방식

처음에는 이미지 데이터를 어떻게 컴퓨터가 읽는지 잘 몰랐다. 조사해보니 이미지는 결국 숫자의 배열로 표현된다는 것을 알게 되었다. 예를 들어 8×8 크기의 이미지는 총 64개의 칸으로 이루어져 있고, 각 칸의 값은 그 부분이 얼마나 밝거나 어두운지를 나타낸다.

즉, 컴퓨터는 이미지를 사람처럼 그림으로 보는 것이 아니라, 64개의 숫자 값을 보고 이 숫자가 0인지, 1인지, 2인지 등을 판단하는 것으로 이해했다.

4. 분석 방법 계획

사용해볼 방법

처음에는 Logistic Regression을 사용해볼 계획이다. 이름에 Regression이 들어가서 처음에는 숫자를 예측하는 방법이라고만 생각했는데, 찾아보니 분류 문제에도 사용할 수 있다는 것을 알게 되었다.

이번 프로젝트에서는 0부터 9까지의 숫자 중 하나를 맞혀야 하므로, 여러 개의 선택지 중 하나를 고르는 분류 문제라고 볼 수 있다. 따라서 Logistic Regression을 사용해서 손글씨 숫자를 분류해보려고 한다.

추가로 해볼 수 있는 방법

시간이 가능하면 kNN이나 SVM 같은 다른 방법도 추가로 비교해볼 수 있을 것 같다. 하지만 현재 단계에서는 여러 모델을 한꺼번에 사용하기보다는, 먼저 하나의 모델로 데이터 불러오기부터 예측까지 전체 흐름을 이해하는 것이 더 중요하다고 생각했다.

평가 방법

모델이 잘 작동하는지는 우선 정확도로 확인할 예정이다. 정확도는 테스트 데이터 중에서 모델이 정답을 맞힌 비율이다. 예를 들어 테스트 데이터 100개 중 95개를 맞혔다면 정확도는 95%가 된다.

최종 블로그에서는 가능하면 혼동행렬도 사용해볼 예정이다. 혼동행렬을 보면 모델이 어떤 숫자를 다른 숫자로 잘못 예측했는지 확인할 수 있다. 예를 들어 숫자 8을 3으로 잘못 판단하는 경우가 있는지 볼 수 있다.

5. 현재 작성 중인 코드

아래 코드는 현재 이해하면서 작성하고 있는 기본 코드이다. 아직 최종 분석이 완성된 것은 아니고, 데이터를 불러오고 모델을 학습시키는 흐름을 먼저 따라가고 있다. 

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix
import matplotlib.pyplot as plt

# 1. 손글씨 숫자 데이터 불러오기
digits = load_digits()

# 2. 이미지 데이터와 정답 숫자 나누기
X = digits.data
y = digits.target

print("입력 데이터 크기:", X.shape)
print("정답 데이터 크기:", y.shape)

# 3. 샘플 이미지 하나 확인하기
plt.imshow(digits.images[0], cmap="gray")
plt.title("Sample digit image")
plt.show()

# 4. 학습용 데이터와 테스트용 데이터로 나누기
X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.3,
    random_state=42
)

# 5. 모델 만들기
model = LogisticRegression(max_iter=3000)

# 6. 모델 학습시키기
model.fit(X_train, y_train)

# 7. 테스트 데이터 예측하기
y_pred = model.predict(X_test)

# 8. 정확도 확인하기
accuracy = accuracy_score(y_test, y_pred)
print("Test Accuracy:", accuracy)

# 9. 혼동행렬 확인하기
cm = confusion_matrix(y_test, y_pred)
print(cm)

현재 코드에서 이해한 부분

  • load_digits()는 손글씨 숫자 데이터를 불러오는 코드이다.
  • X는 이미지 데이터이고, y는 정답 숫자이다.
  • train_test_split()은 데이터를 학습용과 테스트용으로 나누는 코드이다.
  • model.fit()은 모델이 학습하는 과정이다.
  • model.predict()는 모델이 테스트 데이터를 보고 숫자를 예측하는 과정이다.
  • accuracy_score()는 모델이 얼마나 맞혔는지 계산하는 코드이다.

아직 더 이해해야 하는 부분

  • Logistic Regression이 내부적으로 어떻게 분류를 하는지 더 공부해야 한다.
  • 혼동행렬을 표나 그림으로 보기 좋게 나타내는 방법을 더 찾아봐야 한다.
  • 틀린 예측 결과를 이미지로 보여주는 방법을 추가로 시도해보고 싶다.
