1. 프로젝트 제안

주제

이번 프로젝트의 주제는 손글씨 숫자 이미지 분류이다.

주제 선택 이유

AI와 머신러닝을 처음 배울 때 이미지 분류는 결과를 눈으로 확인하기 쉬운 주제라고 생각했다. 숫자는 0부터 9까지 정답이 분명하고, 이미지도 복잡하지 않기 때문에 처음 프로젝트를 진행하기에 적당하다고 판단했다.

처음에는 딥러닝을 바로 적용하는 것도 생각했지만, 아직 모델 구조나 학습 과정이 익숙하지 않기 때문에 우선은 scikit-learn에서 제공하는 손글씨 숫자 데이터셋을 이용해 기본적인 분류 과정을 먼저 해보기로 했다.

최종적으로 확인하고 싶은 내용

  • 손글씨 숫자 이미지가 컴퓨터 안에서 어떤 데이터 형태로 표현되는지 확인한다.
  • 이미지 데이터를 학습 데이터와 테스트 데이터로 나누어본다.
  • 간단한 분류 모델을 사용해 0부터 9까지의 숫자를 예측해본다.
  • 모델이 어떤 숫자를 잘 맞히고, 어떤 숫자에서 헷갈리는지 확인한다.
이 페이지는 최종 결과물이 아니라 프로젝트 진행 상황을 정리한 중간 과정 블로그이다. 현재는 주제 선정, 블로그 개설, 데이터셋 조사, 기본 코드 구상 단계까지 진행하였다.

3. 데이터셋 조사

현재 사용할 데이터셋으로 scikit-learn의 digits 데이터셋을 조사하고 있다. 이 데이터셋은 손글씨 숫자 이미지로 구성되어 있으며, 각 데이터는 0부터 9까지의 숫자 중 하나에 해당한다.

scikit-learn 공식 문서에 따르면 digits 데이터셋은 분류용 데이터셋이며, 각 데이터는 8×8 크기의 손글씨 숫자 이미지이다. 전체 샘플 수는 1797개이고, 각 이미지는 64개의 픽셀 값으로 표현된다.

항목 내용
데이터셋 scikit-learn digits dataset
데이터 종류 손글씨 숫자 이미지
분류 대상 0부터 9까지의 숫자
이미지 크기 8 × 8 픽셀
입력 데이터 64개의 픽셀 값
예측 대상 숫자 라벨

이 데이터셋을 선택한 이유

이 데이터셋은 별도로 이미지를 수집하지 않아도 바로 사용할 수 있고, 데이터 크기도 너무 크지 않다. 또한 숫자 이미지는 결과를 직접 눈으로 확인할 수 있기 때문에, 프로젝트 진행 과정과 결과를 블로그에 설명하기 좋다고 생각했다.

4. 분석 방법 계획

처음에 사용할 방법

처음에는 Logistic Regression을 사용해볼 계획이다. 이 방법은 이름에 Regression이 들어가지만 분류 문제에도 사용할 수 있다. 이번 프로젝트에서는 0부터 9까지 여러 숫자 중 하나를 예측하는 다중 분류 문제로 사용해볼 예정이다.

추가로 비교해볼 수 있는 방법

시간이 가능하면 kNN 또는 SVM도 추가로 사용해보고, 모델별 정확도를 비교할 예정이다. 다만 중간 과정에서는 먼저 한 가지 모델로 데이터 불러오기부터 예측까지의 전체 흐름을 만드는 것을 목표로 한다.

평가 방법

모델 성능은 우선 정확도로 확인할 예정이다. 정확도는 전체 테스트 데이터 중 모델이 정답을 맞힌 비율을 의미한다. 최종 블로그에서는 정확도뿐 아니라 혼동행렬도 함께 확인하여 어떤 숫자끼리 자주 헷갈리는지 살펴볼 계획이다.

5. 현재 작성 중인 코드

아래 코드는 현재 작성 중인 기본 코드이다. 아직 최종 결과를 완성한 상태는 아니며, 데이터를 불러오고 학습 데이터와 테스트 데이터를 나눈 뒤 간단한 모델을 적용하는 흐름을 먼저 잡고 있다. 

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix
import matplotlib.pyplot as plt

# 1. 데이터 불러오기
digits = load_digits()

# 2. 입력 데이터와 정답 라벨 나누기
X = digits.data
y = digits.target

print("입력 데이터 크기:", X.shape)
print("정답 라벨 크기:", y.shape)

# 3. 샘플 이미지 확인
plt.imshow(digits.images[0], cmap="gray")
plt.title("Sample digit image")
plt.show()

# 4. 학습 데이터와 테스트 데이터 나누기
X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.3,
    random_state=42
)

# 5. 모델 생성 및 학습
model = LogisticRegression(max_iter=3000)
model.fit(X_train, y_train)

# 6. 테스트 데이터 예측
y_pred = model.predict(X_test)

# 7. 정확도 확인
accuracy = accuracy_score(y_test, y_pred)
print("Test Accuracy:", accuracy)

# 8. 혼동행렬 확인
cm = confusion_matrix(y_test, y_pred)
print(cm)

현재 코드에서 확인하려는 것

  • X.shape를 통해 입력 데이터의 크기를 확인한다.
  • y.shape를 통해 정답 라벨의 개수를 확인한다.
  • plt.imshow()로 실제 숫자 이미지가 어떻게 보이는지 확인한다.
  • train_test_split()으로 학습 데이터와 테스트 데이터를 나눈다.
  • 모델을 학습시킨 뒤 테스트 정확도를 확인한다.
