1. 프로젝트 제안

주제 선택 이유

이번 프로젝트의 주제는 손글씨 숫자 이미지 분류이다. 사람이 손으로 쓴 숫자는 같은 숫자라도 모양이 조금씩 다르다. 예를 들어 숫자 3을 둥글게 쓰는 사람도 있고, 각지게 쓰는 사람도 있다. 그래서 컴퓨터가 이런 손글씨 숫자를 어떻게 구분하는지 확인해보고 싶었다.

처음에는 이미지 분류가 막연하게 어렵게 느껴졌지만, 이미지는 결국 픽셀 값들이 모인 행렬이라는 것을 알게 되었다. 그래서 이번 프로젝트에서는 손글씨 숫자 이미지를 하나의 그림으로만 보는 것이 아니라, 각 픽셀의 숫자 값으로 이루어진 행렬로 보고 분석해보았다.

딥러닝 모델을 직접 복잡하게 구현하기보다는, 먼저 scikit-learn에서 제공하는 작은 손글씨 숫자 데이터셋을 이용하여 이미지 데이터가 어떻게 숫자 배열로 바뀌고, 그 배열을 이용해 숫자를 분류하는지 확인하는 것을 목표로 하였다.

최종적으로 확인하고 싶은 내용

  • 손글씨 숫자 이미지가 컴퓨터 안에서 어떤 행렬로 표현되는지 확인한다.
  • 8×8 픽셀 행렬이 어떻게 64개의 입력값으로 바뀌는지 확인한다.
  • 픽셀 값을 이용해서 0부터 9까지의 숫자를 분류해본다.
  • 분류 모델이 어느 정도 숫자를 맞히는지 정확도로 확인한다.
  • 어떤 숫자를 잘 맞히고, 어떤 숫자에서 헷갈리는지 혼동행렬로 확인한다.

2. 데이터셋

데이터 설명

이번 프로젝트에서는 scikit-learn의 digits 데이터셋을 사용하였다. 이 데이터셋은 손으로 쓴 숫자 이미지들로 구성되어 있으며, 각 이미지는 0부터 9까지의 숫자 중 하나에 해당한다.

항목 내용
데이터셋 이름 scikit-learn digits dataset
데이터 종류 손글씨 숫자 이미지
전체 샘플 수 1797개
분류 대상 0부터 9까지의 숫자
이미지 크기 8 × 8 픽셀
입력 특성 수 64개

픽셀 행렬 예시

아래는 데이터셋에 포함된 숫자 0 이미지 하나를 8×8 행렬로 나타낸 것이다. 각 숫자는 픽셀의 밝기를 의미한다. 값이 0이면 거의 어두운 부분이고, 값이 클수록 더 밝은 부분이라고 볼 수 있다.

이 행렬을 보면 가운데와 양쪽에 밝은 값들이 몰려 있다. 이러한 픽셀 값의 위치와 밝기 차이를 바탕으로 컴퓨터는 이 이미지가 어떤 숫자인지 판단한다.

행렬에서 벡터로 바꾸는 과정

원래 이미지는 8×8 행렬이지만, 모델에 입력할 때는 이 행렬을 한 줄로 펴서 64개의 값으로 바꾼다. 즉, 하나의 손글씨 숫자 이미지는 다음과 같이 표현된다.

8×8 픽셀 행렬 → 64개의 숫자 값 → 분류 모델 입력

처음에는 이미지가 어떻게 모델에 들어가는지 잘 이해되지 않았지만, 이미지를 작은 칸으로 나누고 각 칸의 밝기를 숫자로 바꾸면 모델이 처리할 수 있다는 점을 확인할 수 있었다.

3. 분석 방법

전체 분석 과정

  1. 손글씨 숫자 데이터셋을 불러온다.
  2. 이미지 데이터와 정답 라벨을 확인한다.
  3. 8×8 픽셀 행렬을 확인한다.
  4. 이미지 데이터를 64개의 입력값으로 사용한다.
  5. 전체 데이터를 학습용 데이터와 테스트용 데이터로 나눈다.
  6. Logistic Regression 모델을 학습시킨다.
  7. 테스트 데이터로 숫자를 예측한다.
  8. 정확도와 혼동행렬을 이용해 결과를 확인한다.

사용한 모델

이번 프로젝트에서는 Logistic Regression을 사용하였다. 이름에는 Regression이 들어가지만, 실제로는 분류 문제에도 사용할 수 있다. 이번 프로젝트는 0부터 9까지 여러 숫자 중 하나를 고르는 문제이므로 다중 분류 문제라고 볼 수 있다.

복잡한 딥러닝 모델을 사용하지 않고 Logistic Regression을 선택한 이유는, 처음 이미지 분류를 공부하는 단계에서는 모델 자체보다 데이터가 어떻게 숫자 형태로 바뀌고, 그 숫자들을 이용해 분류가 이루어지는지를 이해하는 것이 더 중요하다고 생각했기 때문이다.

학습 데이터와 테스트 데이터

전체 1797개의 데이터 중 70%는 모델을 학습시키는 데 사용하고, 30%는 학습이 끝난 모델을 평가하는 데 사용하였다.

구분 개수 역할
전체 데이터 1797개 전체 손글씨 숫자 이미지
학습 데이터 1257개 모델을 학습시키는 데 사용
테스트 데이터 540개 모델 성능을 확인하는 데 사용

분석에 사용한 코드

from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix
import matplotlib.pyplot as plt

# 1. 데이터 불러오기

digits = load_digits()

# 2. 이미지 데이터와 정답 라벨 나누기

X = digits.data
y = digits.target

print("입력 데이터 크기:", X.shape)
print("정답 라벨 크기:", y.shape)

# 3. 첫 번째 이미지의 픽셀 행렬 확인

print("첫 번째 이미지의 8x8 픽셀 행렬")
print(digits.images[0])
print("첫 번째 이미지의 정답:", digits.target[0])

# 4. 학습 데이터와 테스트 데이터로 나누기

X_train, X_test, y_train, y_test = train_test_split(
X, y,
test_size=0.3,
random_state=42,
stratify=y
)

print("학습 데이터 크기:", X_train.shape)
print("테스트 데이터 크기:", X_test.shape)

# 5. 모델 생성 및 학습

model = LogisticRegression(max_iter=5000)
model.fit(X_train, y_train)

# 6. 테스트 데이터 예측

y_pred = model.predict(X_test)

# 7. 정확도 계산

accuracy = accuracy_score(y_test, y_pred)
print("Test Accuracy:", accuracy)

# 8. 혼동행렬 확인

cm = confusion_matrix(y_test, y_pred)
print(cm)

4. 평가 및 분석

정확도 결과

모델을 테스트 데이터 540개에 적용한 결과, 정확도는 약 95.74%로 나타났다. 즉, 테스트 데이터 540개 중 517개를 맞혔고, 23개는 잘못 예측하였다.

결과 해석

대부분의 숫자는 잘 분류되었다. 특히 0, 2, 3, 5, 6, 7은 비교적 높은 정확도로 맞혔다. 반면 숫자 8은 다른 숫자보다 조금 더 많이 헷갈렸다. 혼동행렬을 보면 실제 8인 데이터 중 일부가 1, 5, 6으로 잘못 분류되었다.

이 결과를 보면서 손글씨 숫자 중에서도 8처럼 모양이 복잡하거나 사람마다 다르게 쓰일 수 있는 숫자는 모델이 더 헷갈릴 수 있다는 점을 알 수 있었다. 또한 9도 일부가 8로 잘못 예측되었는데, 손글씨에서 8과 9의 모양이 비슷하게 보일 수 있기 때문이라고 생각했다.

픽셀 행렬 분석 관점에서 본 결과

이 프로젝트에서 가장 중요하게 본 부분은 이미지가 단순한 그림이 아니라 숫자로 된 행렬이라는 점이다. 모델은 사람이 보듯이 “이건 둥글게 생겼으니 0이다”라고 판단하는 것이 아니라, 64개의 픽셀 값이 이루는 패턴을 보고 숫자를 분류한다.

예를 들어 숫자 0의 경우 가운데 부분은 상대적으로 어둡고, 바깥쪽 테두리 부분에 밝은 픽셀 값이 나타나는 경향이 있다. 반면 숫자 1은 세로 방향으로 밝은 값들이 모이는 경우가 많다. 이처럼 각 숫자마다 픽셀 값이 밝게 나타나는 위치가 다르기 때문에 모델이 숫자를 구분할 수 있었다.

6. 결론

이번 프로젝트에서는 손글씨 숫자 이미지를 8×8 픽셀 행렬로 보고, 각 픽셀 값을 이용하여 숫자를 분류해보았다. 처음에는 이미지 분류가 단순히 그림을 보고 맞히는 것처럼 느껴졌지만, 실제로는 이미지를 숫자 행렬로 바꾸고 그 숫자들의 패턴을 이용해 분류한다는 점을 알 수 있었다.

Logistic Regression 모델을 사용한 결과, 테스트 데이터에서 약 95.74%의 정확도를 얻었다. 복잡한 딥러닝 모델을 사용하지 않았는데도 손글씨 숫자를 어느 정도 정확하게 분류할 수 있었다는 점이 흥미로웠다.

혼동행렬을 통해 숫자 8과 9처럼 모양이 복잡하거나 비슷하게 보일 수 있는 숫자에서 예측 오류가 상대적으로 많이 발생한다는 점도 확인하였다. 이를 통해 단순히 정확도만 보는 것보다 어떤 부분에서 모델이 틀렸는지 함께 보는 것이 중요하다는 것을 알게 되었다.
